# JhaMart — APK build without Android Studio

1. Create a GitHub repository named `JhaMart`.
2. Upload the **contents of this project folder** (not the ZIP file itself).
3. Commit to `main` (or `master`).
4. Open **Actions** → **Build JhaMart APK**.
5. Tap **Run workflow**.
6. Wait for the green check.
7. Open the completed run → **Artifacts** → `JhaMart-debug-apk`.
8. Download the artifact ZIP and extract `app-debug.apk`.

This workflow builds a debug APK using GitHub's cloud runner, so Android Studio is not required on your phone.
